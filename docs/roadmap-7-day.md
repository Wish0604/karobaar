# 7-Day Build Roadmap

## Day 1
- Finalize schema + environment + API skeleton.
- Set up shared contracts.

## Day 2
- Merchant onboarding + product catalog CRUD with DB persistence.

## Day 3
- Discovery search + comparison + stock freshness timestamps.

## Day 4
- Reservation lifecycle + inventory holds + order creation.

## Day 5
- AI merchant copilot tools + customer assistant routing.

## Day 6
- Paytm sandbox integration + webhook verification + reconciliation table.

## Day 7
- Test scripts, bug bash, demo narrative, and pitch deck rehearsal.

## Team Split (4 members)
- Dev 1: merchant UI and onboarding.
- Dev 2: customer UI and shopping/reservations.
- Dev 3: backend + database + payment integration.
- Dev 4: AI service + recommendation engine + voice hooks.
